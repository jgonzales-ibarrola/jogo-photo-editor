# My presets

Put your own presets here as `.toml` files. The file name is the preset name.

Example — save as `my-presets/manila-street.toml`, then run `jogo edit --preset manila-street`:

```toml
description = "My street look: warm, contrasty, slight fade."
temperature = 0.1
contrast = 0.3
blacks = 0.15
vibrance = 0.2
sharpen = 0.3
```

A file with the same name as a built-in preset (e.g. `natural.toml`) replaces it.
All slider names and ranges: see `docs/02-tool-reference.md`.
